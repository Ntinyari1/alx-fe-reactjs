React Advanced Form Handling & Operations
This project transitions from manual form management to advanced React patterns, including Formik, React Query, and automated testing.

 Learning Objectives
By the end of this project, you will be able to:

Implement Advanced Form Handling: Manage form data using controlled components and leverage Formik for complex handling.

Handle Advanced Data Operations: Fetch, cache, and update data efficiently using React Query to optimize API interactions.

Utilize Advanced Routing: Create nested, protected, and dynamic routes to manage complex navigation paths.

Implement and Test Components: Build a functional Todo List and test it using Jest and React Testing Library.

 Tech Stack
Core: React, Vite

Forms: Formik, Yup

Data: TanStack Query (React Query)

Routing: React Router

Testing: Jest, React Testing Library
